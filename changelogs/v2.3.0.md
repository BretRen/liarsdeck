# Liar's Deck v2.3.0 更新日志

**发布时间**：2026-08-30

---

### Tailwind CSS v4 + DaisyUI v5 UI 全栈现代化重构
- **UI 视觉体系升级**：升级至 `@tailwindcss/vite`、`tailwindcss@4.3.3` 与 `daisyui@5.7.22`；
- **深邃暗黑黑曜石风格**：全面弃用老旧金色配色，重塑为以深邃黑曜石（Slate-950 / Zinc-900）、科技电光蓝与高饱和猩红构成的现代沉浸式暗黑酒馆视觉；
- **全站组件原子化**：`PlayerSeat`、`TableArea`、`ActionBar`、`HandCards`、`RulesModal`、`AdminModal` 等核心组件全量采用 DaisyUI 5 现代设计系统重构。
