### 动态版本注入与实时探测
- **多层级版本探测**：Go 后端引入 `-ldflags` 编译注入 -> `debug.ReadBuildInfo()` Go 模块元数据 -> 本地 `git describe --tags` 三重回退探测机制；
- **版本 API 暴露**：提供 `GET /api/version` 实时探测接口；
- **前端动态注入**：Vite 编译期注入全局 `__APP_VERSION__`，管理面板支持实时对比本地运行版本与 GitHub Releases 最新版本。
