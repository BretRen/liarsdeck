# Liar's Deck v2.2.0 更新日志

**发布时间**：2026-08-30

---

### Zitadel OAuth2 PKCE 认证体系
- **OIDC 单点登录**：接入 pdnode / Zitadel 认证系统，支持 PKCE 安全授权码流程与强制登录弹窗；
- **唯一账户主键解耦**：彻底与易重名、易变更的 `nickname` 解耦，全系统采用 Zitadel 唯一不可变 `sub` claim 作为全局玩家主键；
- **精确席位认领与防多开**：支持同账号掉线后多端无缝恢复认领原座位，严格阻断同账号多开入座；
- **SPA 回调路由**：Echo 服务端支持 `/callback` 与前端单页面路由 Fallback。
