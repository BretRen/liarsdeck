# Liar's Deck v2.0.0 更新日志

**发布时间**：2026-08-28

---

### 架构重构与特性
- **断线保护机制**：玩家局中断线触发 30 秒游戏暂停保护倒计时，超时自动判定淘汰；
- **开局准备流程**：引入所有玩家准备就绪（Ready）后由房主开局机制；
- **强制质疑规则**：统一规则，当上家打完最后一张手牌时，下家必须强制发起质疑；
- **管理员控制台与自更新**：支持 `Ctrl + X` 呼出管理员面板，集成一键检查 GitHub Releases 更新与后台自更新；
- **Echo 框架现代化**：升级至 Echo v4 现代日志与安全中间件。
